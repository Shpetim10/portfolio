<Chapter id="problem">

History often reaches learners as a wall of dates and names. HERISAGA turns it into a journey: short narratives, interactive questions and review sessions that help learners connect events and understand why they matter. It starts with Albanian history, for students, heritage learners and curious readers in English and Albanian.

</Chapter>

<Chapter id="constraints">

Lessons must feel instant on a phone, yet rewards must be trustworthy: retries, flaky connections and interrupted sessions can never lose progress or award XP twice. Content keeps evolving after release, and the interface has to handle longer Albanian text across both themes.

</Chapter>

<Chapter id="architecture">

A Flutter app, built with Riverpod, go_router and a local Drift/SQLite store, talks to a NestJS API over HTTP/JSON, with Supabase handling authentication. Published episodes arrive as immutable content from a CDN, while answer bundles come from a separate API endpoint. The API grades answers, schedules reviews and records XP, streaks and progress in PostgreSQL through restricted database roles. Shared OpenAPI and JSON Schema contracts keep the app and API aligned.

<Chapter id="decisions">

Separate instant feedback from reward authority. Answers are checked locally, so lessons feel instant, but the server re-grades every submission and alone decides XP, streaks and progression.

Pin each session to a content revision. A lesson in progress never changes under the learner, even when editors publish a new version.

Idempotent events and atomic transactions for progress. A repeated or interrupted request can never duplicate rewards or corrupt a streak.
